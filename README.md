# Brain Tumor Detection

## Overview
This project uses Machine Learning/Deep Learning techniques to detect brain tumors from MRI images. The model analyzes brain scan images and predicts whether a tumor is present, helping to support early diagnosis.

## Features
- Brain tumor detection from MRI images
- Image preprocessing
- Model training and prediction
- Performance evaluation using accuracy and other metrics
- Easy-to-understand implementation in Python

## Technologies Used
- Python
- Jupyter Notebook
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- OpenCV
- Scikit-learn

## Dataset
The project uses a brain MRI dataset containing tumor and non-tumor images for training and testing.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/MHarini-2006/Brain-Tumor-Detection.git
```

2. Install the required libraries:
```bash
pip install -r requirements.txt
```

3. Run the project:
```bash
python braintumordetection.py
```

## Results
The model predicts whether an MRI image contains a brain tumor based on the trained deep learning model.
